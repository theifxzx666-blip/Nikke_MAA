# OCR Evidence Pack

- `full/`: raw task screenshots for OCR and page-state verification.
- `marked/`: screenshots with key OCR regions outlined.
- `manifest.json`: source, task, and purpose mapping for each file.
- `ocr_regression_cases.json`: fixed ROI regression cases consumed by `tools/android_maanikke_debug_apk/scripts/validate_ocr_evidence.ps1`.

Use this pack as a lightweight on-device reference only.
